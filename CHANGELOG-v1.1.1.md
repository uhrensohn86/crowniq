# Crowniq Local v1.1.1

- Android/Firefox: native dropdowns for reliable first-tap operation
- Language-independent stored values are translated when displayed
- Acquisition card redesigned; “Ersparnis gesamt” replaces “Vergünstigungen gesamt”
- Localized purchase/market-value dates
- Case data split into material, finish and coating; added brass, aluminium and resin/plastic
- Dashboard stat cards can be hidden in Settings
- Market value no longer falls back to purchase price; dashboard shows how many watches are valued
- Collection sorting supports ascending and descending order for all current sort criteria
- Existing SQLite databases are migrated automatically with the new case fields
